A ROSE FOR YOU — Romantic Proposal Website
===========================================

FILES
-----
index.html   Main website structure
style.css    Full responsive design and animations
script.js    Shayari generator and interactive buttons

HOW TO RUN
----------
1. Extract the ZIP file.
2. Open the extracted "rose_proposal_website" folder.
3. Double-click index.html to open it in Chrome, Edge, or Firefox.

FEATURES
--------
- Animated CSS rose with petals, leaves, glow and floating motion
- Romantic dark pink theme, sparkles and ambient glow
- 1,000 generated shayari combinations in Hindi
- 1,000 generated shayari combinations in English
- 1,000 generated shayari combinations in Hinglish
- Previous, Next and Surprise Me buttons
- Language switcher
- Proposal reveal and Yes / Let Me Think responses
- Falling rose petals and celebration effects
- Responsive layout for phones, tablets and desktops
- No installation or build tools required

CUSTOMIZATION
-------------
Edit the phrase arrays near the top of script.js to change the shayari.
Edit the page title and text in index.html to personalize the message.
Colors, layout and animations can be changed in style.css.

NOTE
----
The shayari generator creates 1,000 combinations per language from phrase
parts. The page uses Google Fonts when an internet connection is available;
it falls back to standard fonts when offline. All core functionality works
without installing packages.
